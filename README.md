# HeyDev

*"Gastón, I'm done in online store."*

Spoken notifications for Claude Code: hear when Claude finishes a task or needs your attention, with a one-line summary Claude writes itself. Six languages. Local text-to-speech with [Piper](https://github.com/OHF-Voice/piper1-gpl), no API keys. Linux, macOS and Windows.

```
/plugin marketplace add gastonnrodriguez/heydev
/plugin install heydev@heydev
```

Used it when it was called claude-voice? Run `/plugin uninstall voice@claude-voice` and `/plugin marketplace remove claude-voice`, then install it again with the commands above. The engine and the voices you downloaded carry over, so nothing is downloaded again.

**[Full documentation →](plugins/heydev/README.md)**: requirements, configuration, how it works, and everything it runs, downloads and stores.
